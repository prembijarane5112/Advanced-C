# C Programming – Bitwise Operators

## Easy Level – 4 Questions

**1. Check Odd or Even**

Write a program to check whether a given integer is odd or even using bitwise operators.

Test Case 1:

Input:
```text
Enter number: 17
```
Output:
```text
17 is Odd
```

Test Case 2:

Input:
```text
Enter number: 24
```
Output:
```text
24 is Even
```

**2. Set, Clear, and Toggle a Bit**

Write a program to set, clear, and toggle the Nth bit of a given unsigned integer. Assume bit positions start from 0.

Test Case 1:

Input:
```text
Enter number: 10
Enter bit position: 1
```
Output:
```text
After setting bit: 10
After clearing bit: 8
After toggling bit: 8
```

Test Case 2:

Input:
```text
Enter number: 12
Enter bit position: 2
```
Output:
```text
After setting bit: 12
After clearing bit: 8
After toggling bit: 8
```

**3. Count Set Bits**

Write a program to count the number of set bits (bits equal to 1) in a given unsigned integer using bitwise operators.

Test Case 1:

Input:
```text
Enter number: 13
```
Output:
```text
Number of set bits: 3
```

Test Case 2:

Input:
```text
Enter number: 15
```
Output:
```text
Number of set bits: 4
```

**4. Swap Two Numbers Using XOR**

Write a program to swap two integers without using a temporary variable, using the XOR operator.

Test Case 1:

Input:
```text
Enter two numbers: 25 40
```
Output:
```text
After swapping:
a = 40
b = 25
```

Test Case 2:

Input:
```text
Enter two numbers: 10 10
```
Output:
```text
After swapping:
a = 10
b = 10
```

## Medium Level – 3 Questions

**5. Check Power of 2**

Test Case 1:

Input:
```text
Enter number: 64
```
Output:
```text
64 is a power of 2
```

Test Case 2:

Input:
```text
Enter number: 50
```
Output:
```text
50 is not a power of 2
```

**6. Reverse the Bits of an 8-Bit Number**

Write a program to reverse the order of all 8 bits of an unsigned 8-bit integer.

Test Case 1:

Input:
```text
Enter number: 13
```
Output:
```text
Original binary: 00001101
Reversed binary: 10110000
Reversed decimal: 176
```

Test Case 2:

Input:
```text
Enter number: 10
```
Output:
```text
Original binary: 00001010
Reversed binary: 01010000
Reversed decimal: 80
```

**7. Find the Unique Element**

Write a program to find the element that appears only once in an array where every other element appears exactly twice. Use bitwise operators.

Test Case 1:

Input:
```text
Enter N: 7
Enter elements: 4 2 7 2 4 9 7
```
Output:
```text
Unique element: 9
```

Test Case 2:

Input:
```text
Enter N: 5
Enter elements: 5 3 5 7 3
```
Output:
```text
Unique element: 7
```

## Difficult Level – 3 Questions

**8. Rotate Bits to the Left**

Write a program to rotate the bits of an unsigned 8-bit integer to the left by N positions. Bits shifted out from the left must re-enter from the right.

Test Case 1:

Input:
```text
Enter number: 129
Enter rotation count: 1
```
Output:
```text
Original binary: 10000001
Rotated binary: 00000011
Rotated decimal: 3
```

Test Case 2:

Input:
```text
Enter number: 15
Enter rotation count: 2
```
Output:
```text
Original binary: 00001111
Rotated binary: 00111100
Rotated decimal: 60
```

**9. Find Two Unique Elements**

Write a program to find the two elements that appear only once in an array where every other element appears exactly twice. Use bitwise operators.

Test Case 1:

Input:
```text
Enter N: 8
Enter elements: 4 2 7 2 4 9 7 12
```
Output:
```text
Unique elements: 9 12
```

Test Case 2:

Input:
```text
Enter N: 6
Enter elements: 10 20 30 10 40 20
```
Output:
```text
Unique elements: 30 40
```

**10. Multiply and Divide Using Bitwise Operators**

Write a program to multiply a positive integer by 2^N and divide it by 2^N using bitwise operators. Do not use multiplication (*) or division (/) operators for these operations.

Test Case 1:

Input:
```text
Enter number: 5
Enter N: 3
```
Output:
```text
After multiplication: 40
After division: 0
```

Test Case 2:

Input:
```text
Enter number: 24
Enter N: 2
```
Output:
```text
After multiplication: 96
After division: 6
```

**Common Instructions:**
1. Use bitwise operators wherever required.
2. Avoid using predefined functions for the core logic.
3. Assume inputs are within the valid range of the specified data type.
